# HR Analytics & Employee Attrition Prediction

## Project Overview
This project predicts employee attrition using Machine Learning and visualizes HR insights using Power BI.

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Power BI
- Excel

## Features
- Employee Attrition Prediction
- HR Analytics Dashboard
- Feature Importance Analysis
- Department-wise Attrition Analysis

## Machine Learning Algorithm
- Random Forest Classifier

## Business Impact
This system helps organizations reduce employee turnover and improve workforce planning.

## Dashboard Insights
- Attrition Rate
- Salary Analysis
- Department Analysis
- Overtime Impact
- Job Satisfaction Analysis
